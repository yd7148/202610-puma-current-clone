# 復刻 current.puma.taipei 視覺系統

> 教學示範，**非官方網站**。目標網站：[台北大洋流](https://current.puma.taipei/id/)

拆解並重新實作一個高複雜度的品牌活動網站視覺系統，重點在**設計系統層**而非像素複製。

完整分析、踩坑紀錄與架構圖見 [`WORKLOG.md`](./WORKLOG.md)。

## 快速開始

```bash
node _dev-server.js     # http://127.0.0.1:8899
```

| 頁面 | 說明 |
|---|---|
| `/index.html` | 表單 → 生成 9:16 船員證 → 下載 / 分享，含 A/B 插畫與底圖切換 |
| `/compare.html` | 帆船與錨的 A/B 插畫並排比較 |

## 四個核心技巧

1. **硬陰影** — `6px 6px 0 var(--ink)`，實心無模糊，按壓位移等於陰影距離
2. **模糊方波** — SVG `<feGaussianBlur>` 把方波糊成正弦，兩層不同 tile 與速度產生視差
3. **無縫循環** — 動畫位移必須等於 tile 尺寸，否則接縫跳動
4. **手機殼框** — 桌機不重排版面，改把 430px 裝置框畫出來

## A/B 插畫

| | A 木刻墨線 | B 幾何扁平 |
|---|---|---|
| 主導 | `stroke` 粗黑線 | `fill` 無描邊 |
| 線條 | 手繪抖動 | 筆直 |
| 立體 | 墨線壓邊 | 錯色塊 |
| 質感 | 乾刷紋（clip 在船體內） | 無 |

A 版更貼近原圖的「粗黑線 + 印刷不滿版」木刻感。
